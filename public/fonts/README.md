# Lokale Webfonts

Inter (normal, Gewicht 300–500) und Playfair Display (normal/kursiv,
Gewicht 400–600), jeweils Latin und Latin Extended. WOFF2-Dateien wurden am
16.11.2026 über die Google Fonts CSS API bezogen. Die Website lädt sie
von der eigenen Domain und benötigt keine Verbindung zur Fonts API.

Originale und SIL Open Font License 1.1:
- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/playfairdisplay

Die vollständigen Lizenzen liegen in `inter-OFL.txt` und
`playfair-display-OFL.txt`. Zuordnung und Unicode-Bereiche stehen in
`src/styles/fonts.css`.
